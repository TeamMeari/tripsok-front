# 使用条款

**第一条（目的）** 本条款旨在规定梅阿里公司（电子商务经营者）运营的图朗（tourang）（以下简称"商城"）提供的互联网相关服务（以下简称"服务"）时，网络商城与用户之间的权利、义务和责任事项。

※"对于通过PC通信、无线等方式进行的电子商务，除非与其性质相违背，否则也适用本条款。"

**第二条（定义）**

①"商城"是指梅阿里公司为了向用户提供商品或服务（以下简称"商品等"）而利用计算机等信息通信设备设置的可进行商品等交易的虚拟营业场所，同时也指运营网络商城的经营者。

②"用户"是指访问"商城"并根据本条款接受"商城"提供服务的会员及非会员。

③"会员"是指在"商城"进行会员注册，可持续使用"商城"提供服务的个人。

④"非会员"是指未注册会员而使用"商城"提供服务的个人。

**第三条（条款等的明示和说明及修订）**

①"商城"应将本条款的内容及商号、代表姓名、营业场所地址（包括可处理消费者投诉的地址）、电话号码、传真号码、电子邮件地址、营业执照号、通信销售申报号、个人信息管理负责人等在图朗网络商城的初始服务画面（首页）上公示，以便用户容易了解。但条款内容可通过连接画面供用户查看。

②"商城"在用户同意条款前，应通过单独的连接画面或弹出画面等，帮助用户理解条款中规定的要约撤回、配送责任、退款条件等重要内容，并征求用户确认。

③"商城"在不违反《电子商交易等消费者保护法》、《条款规制法》、《电子文档及电子交易基本法》、《电子金融交易法》、《电子签名法》、《信息通信网利用促进及信息保护法》、《访问销售法》、《消费者基本法》等相关法律范围内，可修订本条款。

④"商城"修订条款时，应明确适用日期及修订事由，与现行条款一起在商城初始画面上从适用日期7日前至适用前一日进行公告。但将条款内容变更对用户不利时，应给予至少30日以上的事前宽限期进行公告。此时"商城"应明确比较修订前后的内容，以便用户容易理解。

⑤"商城"修订条款时，修订条款仅适用于适用日期后签订的合同，对于该日期前已签订的合同，仍适用修订前的条款。但已签订合同的用户希望适用修订条款，在第三项规定的修订条款公告期间内向"商城"发送此意向后获得"商城"同意的，适用修订条款。

⑥本条款未规定的事项及本条款的解释，应遵循《电子商交易等消费者保护法》、《条款规制法》、公平交易委员会制定的《电子商交易等消费者保护指南》及相关法律或商业惯例。

**第四条（服务的提供及变更）**

①"商城"执行以下业务：

1. 商品或服务的信息提供及购买合同的签订
2. 已签订购买合同的商品或服务的配送
3. 其他"商城"规定的业务

②"商城"在商品或服务缺货或技术规格变更等情况下，可变更未来合同提供的商品或服务内容。此时应明确变更的商品或服务内容及提供日期，在现商品或服务内容发布处立即公告。

③"商城"因商品等缺货或技术规格变更等事由变更与用户签订的服务内容时，应立即向用户可通知的地址通知该事由。

④前项情况下，"商城"应赔偿用户因此遭受的损失。但"商城"证明无故意或过失的除外。

**第五条（服务中断）**

①"商城"在计算机等信息通信设备的维护检查、更换及故障、通信中断等事由发生时，可暂时中断服务提供。

②"商城"因第一项事由导致服务提供暂时中断，应赔偿用户或第三方因此遭受的损失。但"商城"证明无故意或过失的除外。

③因业务项目转换、业务放弃、企业间合并等事由无法提供服务时，"商城"应按第八条规定的方法通知用户，并按当初"商城"提出的条件向消费者提供补偿。但"商城"未告知补偿标准等的，应向用户支付相当于"商城"通用货币价值的实物或现金，用于用户的里程或积分等。

**第六条（会员注册）**

①用户按"商城"规定的注册表格填写会员信息后，通过表示同意本条款的意思表示申请会员注册。

②"商城"对第一项申请成为会员的用户，除符合以下各项外，应注册为会员：

1. 申请人曾因本条款第七条第三项失去会员资格的，但第七条第三项规定的会员资格丧失后已过3年并获得"商城"会员重新注册同意的除外
2. 注册内容有虚假、遗漏、错误的情况
3. 其他注册为会员在"商城"技术上明显有障碍的情况

③会员注册合同的成立时间为"商城"的同意到达会员时。

④会员在会员注册时注册的事项有变更时，应在合理期限内通过会员信息修改等方法向"商城"告知该变更事项。

**第七条（会员退会及资格丧失等）**

①会员可随时向"商城"请求退会，"商城"应立即处理会员退会。

②会员符合以下各项事由时，"商城"可限制及停止会员资格：

1. 注册申请时注册虚假内容的情况
2. 利用"商城"购买的商品等价款及其他与"商城"利用相关的会员负担债务未按期支付的情况
3. 妨碍他人"商城"利用或盗用信息等威胁电子商交易秩序的情况
4. 利用"商城"进行法律或本条款禁止或违反公序良俗的行为的情况

③"商城"限制、停止会员资格后，同一行为重复2次以上或30日内该事由未纠正的，"商城"可剥夺会员资格。

④"商城"剥夺会员资格时，应删除会员注册。此时应通知会员，并在删除会员注册前给予至少30日以上的说明机会。

**第八条（对会员的通知）**

①"商城"对会员进行通知时，可向会员与"商城"事先约定的指定电子邮件地址发送。

②"商城"对不特定多数会员的通知，可通过在"商城"公告板上发布1周以上代替个别通知。但与会员本人交易相关有重大影响的事项应进行个别通知。

**第九条（购买申请及个人信息提供同意等）**

①"商城"用户通过以下或类似方法在"商城"上申请购买，"商城"在用户申请购买时应以易懂的方式提供以下各项内容：

1. 商品等的搜索及选择
2. 收货人姓名、地址、电话号码、电子邮件地址（或手机号码）等的输入
3. 条款内容、要约撤回权受限制的服务、配送费、安装费等费用负担相关内容的确认
4. 同意本条款并确认或拒绝上述3项事项的表示（如鼠标点击）
5. 商品等的购买申请及对此的确认或对"商城"确认的同意
6. 支付方式的选择

②"商城"需要向第三方提供购买者个人信息时，应向购买者告知1）个人信息接收者，2）个人信息接收者的个人信息利用目的，3）提供的个人信息项目，4）个人信息接收者的个人信息保有及利用期间，并获得同意。（获得同意的事项变更时也相同。）

③"商城"委托第三方处理购买者个人信息时，应向购买者告知1）个人信息处理受托者，2）个人信息处理委托的业务内容，并获得同意。（获得同意的事项变更时也相同。）但为服务提供相关合同履行所需且与购买者便利增进相关时，可通过《信息通信网利用促进及信息保护法》规定的方法，通过个人信息处理政策告知，省略告知程序及同意程序。

**第十条（合同成立）**

①"商城"对第九条规定的购买申请，符合以下各项时可不予同意。但与未成年人签订合同时，应告知如未获得法定代理人同意，未成年人本人或法定代理人可取消合同：

1. 申请内容有虚假、遗漏、错误的情况
2. 未成年人购买《青少年保护法》禁止的烟草、酒类等商品及服务的情况
3. 其他同意购买申请在"商城"技术上明显有障碍的情况

②"商城"的同意以第十二条第一项规定的收信确认通知形式到达用户时，视为合同成立。

③"商城"的同意意思表示应包含对用户购买申请的确认及销售可能性、购买申请的订正取消等相关信息。

**第十一条（支付方法）**"商城"购买的商品或服务价款支付方法可采用以下方法中可用的方法。但"商城"不得对用户的支付方法在商品等价款上收取任何名目的手续费。

1. 电话银行、网络银行、邮件银行等各种账户转账
2. 预付卡、借记卡、信用卡等各种卡支付
3. 在线无账户存款
4. 电子货币支付
5. 收货时付款
6. "商城"支付的里程等积分支付
7. 与"商城"签约或"商城"认可的商品券支付
8. 其他电子支付方法等

**第十二条（收信确认通知、购买申请变更及取消）**

①"商城"在用户有购买申请时，应向用户发送收信确认通知。

②收到收信确认通知的用户在意思表示不一致等情况下，可在收到收信确认通知后立即请求购买申请变更及取消，"商城"在配送前有用户请求时，应无迟延地按该请求处理。但已支付价款时，按第十五条要约撤回等规定执行。

**第十三条（商品等的供应）**

①"商城"与用户对商品等供应时间无特别约定的，应在用户要约之日起7日内采取订货制作、包装等其他必要措施，以便配送商品等。但"商城"已收到商品等价款全部或部分时，应在收到价款全部或部分之日起3个营业日内采取措施。此时"商城"应采取适当措施，使用户可确认商品等的供应程序及进展情况。

②"商城"应明确用户购买商品的配送手段、各手段配送费用负担者、各手段配送期间等。如"商城"超过约定配送期间，应赔偿用户因此遭受的损失。但"商城"证明无故意、过失的除外。

**第十四条（退款）**"商城"在用户申请购买的商品等因缺货等事由无法交付或提供时，应立即向用户通知该事由，如事先收到商品等价款，应在收到价款之日起3个营业日内退款或采取退款必要措施。

**第十五条（要约撤回等）**

①与"商城"签订商品等购买合同的用户，可在收到《电子商交易等消费者保护法》第十三条第二项规定的合同内容相关书面文件之日（如商品等供应晚于收到书面文件，指收到商品等供应或商品等供应开始之日）起7日内撤回要约。但《电子商交易等消费者保护法》对要约撤回有不同规定的，按该法规定执行。

②用户收到商品等配送后，符合以下各项之一的，不得退货及换货：

1. 因用户责任事由导致商品等灭失或毁损的情况（但为确认商品等内容而毁损包装等的，可撤回要约）
2. 因用户使用或部分消费导致商品等价值显著减少的情况
3. 因时间经过导致商品等价值显著减少至难以再销售程度的情况
4. 具有相同性能的商品等可复制时，毁损该原商品等包装的情况

③第二项第二号至第四号情况下，如"商城"未事先在消费者容易了解的地方明示要约撤回等受限制的事实或提供试用商品等措施，用户要约撤回等不受限制。

④用户不受第一项及第二项规定限制，商品等内容与表示、广告内容不同或合同内容履行不同时，可在收到该商品等之日起3个月内，或知道或应知道该事实之日起30日内撤回要约等。

**第十六条（要约撤回等的效果）**

①"商城"收到用户返还商品等时，应在3个营业日内退还已收到的商品等价款。此时"商城"向用户延迟退还商品等的，应按《电子商交易等消费者保护法施行令》第二十一条之二规定的延迟利率计算延迟利息并支付。

②"商城"退还上述价款时，如用户以信用卡或电子货币等支付手段支付商品等价款，应立即要求提供该支付手段的经营者停止或取消商品等价款请求。

③要约撤回等情况下，返还已供应商品等所需费用由用户负担。"商城"不得以要约撤回等为由向用户请求违约金或损害赔偿。但商品等内容与表示、广告内容不同或合同内容履行不同导致要约撤回等的，返还商品等所需费用由"商城"负担。

④用户收到商品等时负担发送费的，"商城"应在要约撤回时明确标示该费用由谁负担，以便用户容易了解。

**第十七条（个人信息保护）**

①"商城"在收集用户个人信息时，应在服务提供所需范围内收集最少必要的个人信息。

②"商城"不在会员注册时预先收集购买合同履行所需信息。但相关法律义务履行需要购买合同前身份确认且收集最少特定个人信息的除外。

③"商城"收集、利用用户个人信息时，应向该用户告知目的并获得同意。

④"商城"不得将收集的个人信息用于目的外用途，新利用目的发生或向第三方提供时，应在利用、提供阶段向该用户告知目的并获得同意。但相关法律有不同规定的除外。

⑤"商城"按第二项及第三项需获得用户同意时，应事先明示或告知个人信息管理负责人身份（所属、姓名及电话号码、其他联系方式）、信息收集目的及利用目的、向第三方信息提供相关事项（接收者、提供目的及提供信息内容）等《信息通信网利用促进及信息保护法》第二十二条第二项规定的事项，用户可随时撤回该同意。

⑥用户可随时要求查阅及更正"商城"持有的自己个人信息，"商城"有义务无迟延地采取必要措施。用户要求更正错误的，"商城"在更正该错误前不得利用该个人信息。

⑦"商城"为个人信息保护，应将处理用户个人信息的人员限制在最少，对包括信用卡、银行账户等用户个人信息的丢失、被盗、泄露、未经同意向第三方提供、变造等导致用户损失承担全部责任。

⑧"商城"或从该处接收个人信息的第三方，在个人信息收集目的或接收目的达成时，应立即销毁该个人信息。

⑨"商城"不得将个人信息收集、利用、提供相关同意栏预设为已选择。且个人信息收集、利用、提供相关用户拒绝同意时限制的服务应具体明示，不得以非必需收集项目的个人信息收集、利用、提供相关用户拒绝同意为由限制或拒绝会员注册等服务提供。

**第十八条（"商城"的义务）**

①"商城"不得进行法律及本条款禁止或违反公序良俗的行为，应按本条款规定持续、稳定地提供商品、服务，尽最大努力。

②"商城"应具备保护用户个人信息（包括信用信息）的安全系统，使用户安全利用互联网服务。

③"商城"对商品或服务进行《表示、广告公正化法》第三条规定的不当表示、广告行为导致用户损失的，应承担赔偿责任。

④"商城"不发送用户不希望的营利目的广告性电子邮件。

**第十九条（会员ID及密码相关义务）**

①除第十七条情况外，ID和密码管理责任在会员。

②会员不得让第三方使用自己的ID及密码。

③会员发现自己的ID及密码被盗或第三方使用时，应立即向"商城"通报，有"商城"指导时应按该指导执行。

**第二十条（用户义务）用户不得进行以下行为：**

1. 申请或变更时注册虚假内容
2. 盗用他人信息
3. 更改"商城"发布的信息
4. 发送或发布"商城"规定信息以外的信息（计算机程序等）
5. 侵犯"商城"及其他第三方的版权等知识产权
6. 损害"商城"及其他第三方名誉或妨碍业务的行为
7. 在商城公开或发布淫秽或暴力信息、图像、声音及其他违反公序良俗信息的行为

**第二十一条（连接"商城"与被连接"商城"间关系）**

①上位"商城"与下位"商城"通过超链接（如超链接对象包括文字、图像及动态图像等）方式等连接时，前者称为连接"商城"（网站），后者称为被连接"商城"（网站）。

②连接"商城"在被连接"商城"独立提供的商品等与用户进行交易时，如连接"商城"在初始画面或连接时点的弹出画面明示不承担保证责任，则对该交易不承担保证责任。

**第二十二条（版权归属及利用限制）**

①"商城"创作的著作物的版权及其他知识产权归"商城"所有。

②用户不得将利用"商城"获得的信息中归"商城"所有的知识产权信息，未经"商城"事先同意，以复制、发送、出版、分发、广播及其他方法营利利用或让第三方利用。

③"商城"按约定利用归用户所有的版权时，应向该用户通报。

**第二十三条（纠纷解决）**

①"商城"为反映用户提出的正当意见或投诉并处理其损失补偿，应设置、运营损失补偿处理机构。

②"商城"应优先处理用户提交的投诉事项及意见。但迅速处理困难时，应立即向用户通报事由及处理日程。

③"商城"与用户间发生电子商交易纠纷时，如有用户损失救济申请，可按公平交易委员会或市、道知事委托的纠纷调解机构的调解执行。

**第二十四条（裁判权及准据法）**

①"商城"与用户间发生的电子商交易纠纷相关诉讼，按起诉时用户地址，无地址时按住所管辖地方法院专属管辖。但起诉时用户地址或住所不明确或为外国居住者时，按民事诉讼法管辖法院起诉。

②"商城"与用户间提起的电子商交易诉讼适用韩国法。
